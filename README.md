# ProbabilisticChanVese

Miniproject: Chan Vese segmentation, a probabilistic approach.

 The following project is carried out as part of the course 
 02506 Advanced Image Analysis (Spring, 2021), at the Technical 
 University of Denmark (DTU).

 This project aims to implement the solution described in:
 Vedrana Andersen Dahl and Anders Bjorholm Dahl. A probabilistic framework for curve evolution. 
 In Scale Space and Variational Methods in Computer Vision, pages 421–32. Springer, 2017
 
 Authors : Mario Corral Bolaños & Sheyla Barrado Ballestero
